Kirade App Reports Privacy Policy

Effective: October 21, 2026

Kirade App Reports is a personal tool used by one person, its owner, to view the ad performance of the owner's own apps. It is not offered to the public, and it has no other users.

In short
  • The tool asks for one read-only Google permission and reads only the owner's own AdMob data.
  • It does not write to or change anything in the owner's Google account.
  • The data is not sold, not shared with third parties and not used for advertising.
  • There is no server run for this tool.

1. Who is responsible

The operator is Kirade (an individual developer), who is also the only user. Questions about privacy: kirade.apps+reports@gmail.com.

2. What Google data the tool accesses

The tool uses the AdMob API and requests a single read-only scope:

  • https://www.googleapis.com/auth/admob.readonly

With this scope, the tool reads the owner's own AdMob account information, the list of the owner's apps and ad units, and performance and revenue reports. It does not access any other Google data, and it does not write or change anything.

3. How the data is used

Reports are retrieved on the owner's computer, only to review the performance of the owner's own apps. The owner may have AI assistant software, such as Anthropic's Claude, analyze these reports on the owner's behalf.

4. Storage of credentials

The OAuth credentials (client ID, client secret and refresh token) are kept in the owner's personal secrets store (Infisical). No server is operated for this tool.

5. Sharing

The data is not sold and is not shared with third parties. It is not used for advertising.

6. Google API Services User Data Policy

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

8. Contact and changes

Contact: kirade.apps+reports@gmail.com. If this policy changes, the new version is posted here with a new effective date.

Effective: October 21, 2026

Kirade App Reports 개인정보처리방침

시행일: 2026년 10월 21일

Kirade App Reports는 소유자 한 사람이 자신의 앱 광고 실적을 보려고 쓰는 개인 도구입니다. 일반에 제공하지 않으며 다른 사용자는 없습니다.

1. 책임자

운영자는 개인 개발자 Kirade이며, 유일한 사용자이기도 합니다. 문의: kirade.apps+reports@gmail.com

2. 접근하는 Google 데이터

이 도구는 AdMob API를 사용하며 읽기 전용 권한 범위 하나만 요청합니다.

  • https://www.googleapis.com/auth/admob.readonly

이 범위로 소유자 자신의 AdMob 계정 정보, 앱·광고 단위 목록, 실적·수익 리포트를 읽습니다. 다른 Google 데이터에는 접근하지 않으며, 쓰기나 변경도 하지 않습니다.

3. 데이터 이용

리포트는 소유자의 컴퓨터에서 조회하며, 소유자 자신의 앱 실적을 확인하는 데에만 씁니다. 소유자는 대신 일을 맡기는 AI 도우미 소프트웨어(예: Anthropic의 Claude)로 이 리포트를 분석할 수 있습니다.

4. 자격 증명 보관

OAuth 자격 증명(클라이언트 ID, 클라이언트 시크릿, refresh token)은 소유자의 개인 시크릿 저장소(Infisical)에 보관합니다. 이 도구를 위해 따로 운영하는 서버는 없습니다.

5. 공유

데이터를 판매하거나 제3자와 공유하지 않으며, 광고에 쓰지 않습니다.

6. Google API 서비스 사용자 데이터 정책

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. 접근 철회

https://myaccount.google.com/permissions에서 언제든지 접근 권한을 철회할 수 있습니다.

8. 문의 및 변경

문의: kirade.apps+reports@gmail.com. 방침이 바뀌면 새 시행일과 함께 이 페이지에 게시합니다.
