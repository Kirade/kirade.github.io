Kirade Mail Setup Privacy Policy

Effective: October 21, 2026

Kirade Mail Setup is a personal tool used by one person, its owner, to create labels and filters in the owner's own Gmail account for the owner's app contact addresses (addresses using a + alias). It is not offered to the public, and it has no other users.

In short
  • The tool asks for two Google permissions: one to view and create labels, one to view and create filters.
  • It does not read, send or delete email.
  • The only filters it creates apply one label to mail sent to a specific address. It does not create filters that delete, skip the inbox or forward.
  • The data is not sold, not shared with third parties and not used for advertising.
  • There is no server run for this tool.

1. Who is responsible

The operator is Kirade (an individual developer), who is also the only user. Questions about privacy: kirade.apps+reports@gmail.com.

2. What Google data the tool accesses

The tool uses the Gmail API and requests two scopes:

  • https://www.googleapis.com/auth/gmail.labels (view and create labels)
  • https://www.googleapis.com/auth/gmail.settings.basic (view and create filters)

With these scopes, the tool lists the owner's existing labels and filters and creates new labels and filters. It does not request any scope that allows reading email content or sending email. In principle, the filter permission could also be used to create filters that delete or forward email, but this tool only creates filters that apply a single label to mail sent to a specific address, and it does not create filters that delete, skip the inbox or forward. It does not modify or delete existing labels or filters.

3. How the data is used

The tool runs on the owner's computer, only to set up labels and filters for the owner's own contact addresses. The owner may have AI assistant software, such as Anthropic's Claude, run the tool on the owner's behalf.

4. Storage of credentials

The OAuth credentials (client ID, client secret and refresh token) are kept in the owner's personal secrets store (Infisical). No server is operated for this tool.

5. Sharing

The data is not sold and is not shared with third parties. It is not used for advertising.

6. Google API Services User Data Policy

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

8. Contact and changes

Contact: kirade.apps+reports@gmail.com. If this policy changes, the new version is posted here with a new effective date.

Kirade Mail Setup 개인정보처리방침

시행일: 2026년 10월 21일

Kirade Mail Setup은 소유자 한 사람이 자신의 앱 문의 주소(+ 별칭 주소)용 라벨과 필터를 소유자 본인의 Gmail 계정에 만들려고 쓰는 개인 도구입니다. 일반에 제공하지 않으며 다른 사용자는 없습니다.

1. 책임자

운영자는 개인 개발자 Kirade이며, 유일한 사용자이기도 합니다. 문의: kirade.apps+reports@gmail.com

2. 접근하는 Google 데이터

이 도구는 Gmail API를 사용하며 권한 범위 두 개를 요청합니다.

  • https://www.googleapis.com/auth/gmail.labels (라벨 보기·만들기)
  • https://www.googleapis.com/auth/gmail.settings.basic (필터 보기·만들기)

이 범위로 소유자의 기존 라벨과 필터 목록을 조회하고 새 라벨과 필터를 만듭니다. 메일 본문을 읽거나 메일을 보내는 범위는 요청하지 않습니다. 필터 권한으로는 원칙적으로 메일을 지우거나 전달하는 필터도 만들 수 있지만, 이 도구는 특정 받는사람 주소로 온 메일에 라벨 하나를 붙이는 필터만 만들고, 메일을 지우거나 받은편지함을 건너뛰거나 전달하는 필터는 만들지 않습니다. 기존 라벨과 필터를 고치거나 지우지도 않습니다.

3. 데이터 이용

이 도구는 소유자의 컴퓨터에서 실행되며, 소유자 자신의 문의 주소용 라벨과 필터를 설정하는 데에만 씁니다. 소유자는 대신 일을 맡기는 AI 도우미 소프트웨어(예: Anthropic의 Claude)로 이 도구를 실행하게 할 수 있습니다.

4. 자격 증명 보관

OAuth 자격 증명(클라이언트 ID, 클라이언트 시크릿, refresh token)은 소유자의 개인 시크릿 저장소(Infisical)에 보관합니다. 이 도구를 위해 따로 운영하는 서버는 없습니다.

5. 공유

데이터를 판매하거나 제3자와 공유하지 않으며, 광고에 쓰지 않습니다.

6. Google API 서비스 사용자 데이터 정책

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. 접근 철회

https://myaccount.google.com/permissions에서 언제든지 접근 권한을 철회할 수 있습니다.

8. 문의 및 변경

문의: kirade.apps+reports@gmail.com. 방침이 바뀌면 새 시행일과 함께 이 페이지에 게시합니다.
